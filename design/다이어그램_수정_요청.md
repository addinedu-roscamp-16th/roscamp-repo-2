# 다이어그램 수정 요청

다른 문서(관리자 · 사용자 스토리보드, 기능 목록 등)를 만들다가 찾은, 다이어그램에 반영할 일을 모아 둡니다.
한꺼번에 반영을 요청할 때 이 목록을 씁니다. 반영하면 상태를 "반영됨"으로 바꾸고 그때의 다이어그램 버전을 적습니다.

- 상태: **요청**(바로 반영 가능) · **결정 필요**(팀 결정 뒤 반영) · **반영됨**
- 스토리보드 노트에는 "다이어그램 수정 요청 R-01"처럼 번호만 적어 서로 찾습니다.
