# 원본 공식 실행 결과 (근거 사본)

[코딩 규칙 검토 사항](../코딩_규칙_검토_사항.md)이 인용하는 통합·부하 시험 결과의 사본입니다.

- 이 결과는 팀 저장소에서 실행한 것이 아닙니다. 원본 저장소에서 실제 ROS 2 노드와 장비 2대로 실행한 결과입니다.
- 팀 저장소에서 실행하는 시험은 [단위 시험](../unit/)뿐입니다. 이 폴더의 `UT-*.json`은 원본 저장소에서 실행한 기록이며, 팀 단위 시험의 실행 결과가 아닙니다.

## 출처

| 항목 | 내용 |
|---|---|
| 실행 ID | `20261109-211124` (공식 실행) |
| 실행 환경 | Ubuntu 24.04, ROS 2 Jazzy, PC 1대 + 라즈베리파이 1대, `ROS_DOMAIN_ID=99` |
| 결과 요약 | 15건 중 통과 14건, 미실행 1건(UT-02: 최소 브리지에 Action 경로 없음) |

## 인용 방법

검토 문서에서 결과를 인용할 때는 실행 ID, 항목 ID, 관측값, 파일 경로를 함께 적습니다.

> 예: 실행 `20261109-211124` LT-01: 지정 10건 재전송, 발행 종료 후 2.286초에 미확인 0건, DB 저장 1,000건
> ([LT-01.json](20261109-211124/LT-01.json))

## 항목별 파일

| ID | 파일 | 내용 |
|---|---|---|
| IT-01, IT-01-대조 | `IT-01.json`, `IT-01-대조.json` | 서비스 응답 대기 중 타이머 동작, 블로킹 `call()` 교착 대조 |
| IT-02 | `IT-02.json` | callback group 분리 시 상태 콜백 간격 |
| IT-03 | `IT-03-접수전.json`, `IT-03-접수후.json` | 접수 전후 재시작 시 상태 조회와 중복 실행 방지 |
| IT-04 | `IT-04.json` | QoS 불일치 감지 |
| LT-01 | `LT-01.json` | 알림 1,000건, ACK 누락 시 재전송과 저장 |
| LT-02 | `LT-02.json` | 로봇 10대 상태, 느린 소비자에서 최신값 유지 |
| LT-03 | `LT-03.json` | WS 재연결 후 `since_seq` 재생 |
| UT-01~05 | `UT-*.json` | 원본 저장소의 단위 시험 기록 (참고용) |

## 사용 범위

이 결과는 설계 검토를 위한 단위 기능 시험용으로 제한됩니다.

- 시험용 최소 브리지로 규칙이 의도대로 동작하는지 확인한 결과입니다.
- 팀 제품 코드의 검증 결과나 성능 기준으로 쓰지 않습니다.
