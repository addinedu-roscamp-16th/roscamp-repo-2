# ROS 2 통신 시험 절차 안내

ROS 2 통신 시험(1·2단계)을 처음 실행하는 사람을 위한 순서 안내입니다.

- 무엇을 왜 시험하는지는 [시험 계획서](../ROS2_통신_안내_시험_계획서.md)에 있습니다.
- 실행 도구의 옵션, 판정 규칙, 결과 파일 형식은 [README](README.md)에 있습니다.
- 이 문서는 "어떤 순서로 무엇을 하면 되는지"와 "막혔을 때 어떻게 하는지"만 다룹니다.

## 1. 전체 흐름

| 순서 | 할 일 | 장비 | 걸리는 시간 |
|---|---|---|---|
| 1 | PC 준비 | PC | 처음 한 번 |
| 2 | 1단계 실행 (L-01, L-03) | PC | 약 30분 |
| 3 | 라즈베리파이 준비 (SSH 키, 영상 도구, 방화벽) | PC + 라즈베리파이 | 처음 한 번 |
| 4 | 2단계 미리 돌려 보기 | PC (+ 라즈베리파이) | 5~10분 |
| 5 | 2단계 공식 실행 (L-01-W, L-02, L-04, G-11) | PC + 라즈베리파이 | 약 1시간 40분 |
| 6 | 결과 확인과 보관 | PC | 10분 |

명령은 모두 저장소 맨 위 폴더(`roscamp-repo-2`)에서 실행한다고 가정합니다.

## 2. PC 준비

1. ROS 2 Jazzy가 설치되어 있어야 합니다.
2. 터미널을 열 때마다 ROS 환경을 불러옵니다.

   ```bash
   source /opt/ros/jazzy/setup.bash
   ```

   - `run_stage1.sh`, `run_stage2.sh`는 ROS 환경이 없으면 스스로 불러옵니다.
   - `run_l02.py`, `run_l04.py` 같은 개별 실행 도구는 스스로 불러오지 않습니다. 개별 도구를 쓸 때는 위 명령을 먼저 실행합니다.
3. 단위 시험으로 도구가 정상인지 확인합니다.

   ```bash
   python3 -m pytest tests/ros2_guide/unit -q
   ```

4. 통신 구역 번호(`ROS_DOMAIN_ID`)를 확인합니다.
   - 따로 정하지 않으면 도구가 87을 씁니다.
   - `~/.bashrc`에 다른 값을 넣어 두었다면 도구는 그 값을 씁니다. 87로 고정하려면 실행할 때 앞에 `ROS_DOMAIN_ID=87`을 붙입니다.
   - 시험 중에는 같은 번호를 쓰는 다른 ROS 프로그램을 끕니다. 섞이면 결과가 틀어집니다.

## 3. 1단계 실행 (PC 1대)

1. 소량으로 먼저 확인합니다. 결과는 공식 판정이 아닙니다.

   ```bash
   tests/ros2_guide/run_stage1.sh --trials 2 --seconds 3 --run-id dev-check
   ```

2. 공식 실행을 합니다. 약 30분 걸립니다.

   ```bash
   tests/ros2_guide/run_stage1.sh
   ```

3. 끝나면 결과 요약이 화면에 나옵니다. 결과 파일은 `tests/ros2_guide/results/<실행 ID>/`에 저장됩니다.

- 실행 ID를 정하지 않으면 `날짜-시각`(예: `20261111-192323`)으로 정해집니다.
- 실행 중에는 PC에서 무거운 작업을 하지 않습니다.

## 4. 라즈베리파이 준비 (처음 한 번)

### 4.1 기본 조건

- 라즈베리파이에 ROS 2 Jazzy가 `/opt/ros/jazzy`에 설치되어 있어야 합니다.
- PC와 라즈베리파이가 **같은 공유기**에 연결되어 있어야 합니다.
- 시험 전용 라즈베리파이를 씁니다. 시험 도구는 정리할 때 라즈베리파이의 모든 `gst-launch-1.0` 프로세스를 끕니다.

### 4.2 SSH 키 로그인

시험 도구는 비밀번호 없이 SSH로 라즈베리파이에 접속합니다.

1. PC의 `~/.ssh/config`에 라즈베리파이를 등록합니다. 이름(`Host`)은 자유롭게 정합니다.

   ```text
   Host sbt-pi
       HostName <라즈베리파이 IP>
       User <라즈베리파이 사용자 이름>
       IdentityFile ~/.ssh/<키 파일>
   ```

2. 키가 없으면 만들고, 라즈베리파이에 등록합니다. 등록할 때 라즈베리파이 비밀번호를 한 번 입력합니다.

   ```bash
   ssh-keygen -t ed25519 -f ~/.ssh/<키 파일>
   ssh-copy-id -i ~/.ssh/<키 파일>.pub sbt-pi
   ```

3. 비밀번호 없이 접속되는지 확인합니다. 아무것도 묻지 않고 끝나면 성공입니다.

   ```bash
   ssh -o BatchMode=yes sbt-pi true
   ```

### 4.3 영상 도구 (L-04 영상 동시 조합에 필요)

라즈베리파이에 H.264 인코더(`x264enc`)가 있는지 확인합니다.

```bash
ssh sbt-pi 'gst-inspect-1.0 x264enc >/dev/null 2>&1 && echo 있음 || echo 없음'
```

"없음"이면 설치합니다. 관리자 비밀번호를 묻습니다.

```bash
ssh -t sbt-pi sudo apt install -y gstreamer1.0-plugins-ugly
```

### 4.4 PC 방화벽

라즈베리파이가 보내는 UDP를 PC가 받을 수 있어야 합니다. 방화벽(`ufw`)을 쓰는 경우에만 필요합니다. 시험할 때만 열어 두면 됩니다.

```bash
sudo ufw allow proto udp from <라즈베리파이 IP> to any port 29150:29399
sudo ufw allow proto udp from <라즈베리파이 IP> to any port 5600
```

포트의 의미는 README의 "방화벽 (PC)" 절에 있습니다.

## 5. 2단계 미리 돌려 보기

공식 실행 전에 두 가지를 확인합니다. 둘 다 공식 판정이 아닙니다.

1. PC 1대로 도구가 끝까지 도는지 확인합니다.

   ```bash
   tests/ros2_guide/run_stage2.sh --quick --run-id dev-s2
   ```

2. 라즈베리파이와 연결해서 짧게 돌려 봅니다. 사전 점검(SSH, 코드 복사, 양방향 통신, 영상 도구)이 함께 돌아갑니다.

   ```bash
   PI_HOST=sbt-pi tests/ros2_guide/run_stage2.sh --quick --run-id pi-check
   ```

   - 사전 점검에서 막히면 아무 시험도 돌지 않고 멈춥니다. 원인은 화면과 `preflight.json`에 나옵니다.
   - 한 시험만 다시 확인할 때는 개별 도구를 씁니다. 이때는 ROS 환경을 먼저 불러옵니다.

     ```bash
     source /opt/ros/jazzy/setup.bash && python3 tests/ros2_guide/run_l04.py --pi-host sbt-pi --seconds 20 --run-id pi-l04-check
     ```

## 6. 2단계 공식 실행

1. 라즈베리파이와 PC를 같은 공유기에 연결하고, 위의 미리 돌려 보기가 통과했는지 확인합니다.
2. 실행합니다. 약 1시간 40분 걸립니다.

   ```bash
   PI_HOST=sbt-pi tests/ros2_guide/run_stage2.sh
   ```

3. 실행 중에는 같은 공유기에서 큰 파일 내려받기나 영상 시청을 피합니다. 결과에 섞입니다.
4. 중간에 끊기면 같은 실행 ID로 이어서 실행합니다. 끝난 조합은 건너뛰고, 실패했거나 남은 조합만 다시 돕니다.

   ```bash
   PI_HOST=sbt-pi tests/ros2_guide/run_stage2.sh --run-id <끊긴 실행 ID> --resume
   ```

5. 어떤 라즈베리파이(기종, 호스트 이름)로 측정했는지 따로 적어 둡니다. 기종에 따라 결과가 달라집니다.

## 7. 결과 확인과 보관

1. 화면의 결과 요약을 확인합니다. 결과 값의 뜻은 다음과 같습니다.

   | 값 | 뜻 |
   |---|---|
   | 통과 | 규칙 변형이 기준을 모두 만족함 |
   | 실패 | 규칙 변형이 기준을 만족하지 못함 |
   | 측정 | 합격 기준이 없는 항목. 값만 기록함 |
   | 판정 불가 | 측정이 온전하지 않아 판단할 수 없음 |
   | 미실행 | 실행하지 않음 |

2. 자세한 값은 `tests/ros2_guide/results/<실행 ID>/`의 JSON 파일에 있습니다. 이 폴더는 커밋하지 않습니다.
3. 근거로 인용할 공식 실행만 `evidence/`에 사본으로 남기고 커밋합니다.

   ```bash
   mkdir -p tests/ros2_guide/evidence
   cp -r tests/ros2_guide/results/<실행 ID> tests/ros2_guide/evidence/
   ```

4. 공식 실행 결과는 [시험 결과 보고서](시험_결과_보고서.html)에 반영합니다.

## 8. 막혔을 때

| 증상 | 원인 | 해결 |
|---|---|---|
| `No such file or directory` (스크립트 실행 시) | 지금 폴더 기준으로 경로가 맞지 않음 | 저장소 맨 위 폴더로 이동하거나, 스크립트를 전체 경로로 실행 |
| 시작하자마자 멈춤, "실행 ID ...에 이미 결과가 있습니다" | 같은 실행 ID의 결과가 이미 있음 | 새 `--run-id`를 쓰거나, 이어서 할 때는 `--resume` |
| SSH 오류(`rc=255`), `No route to host` | 라즈베리파이 IP가 바뀜 | 라즈베리파이에서 `hostname -I`로 IP 확인 후 `~/.ssh/config`의 `HostName` 수정 |
| `Permission denied (publickey)` | 라즈베리파이에 PC의 키가 등록되지 않음 (재설치, 다른 라즈베리파이 등) | `ssh-copy-id -i ~/.ssh/<키 파일>.pub <호스트>` |
| 사전 점검에서 라즈베리파이 → PC만 0건 | PC 방화벽이 막음 | 4.4절대로 UDP 허용 |
| L-04 전 조합 "관제 노드가 READY를 내지 않음" | 개별 도구를 ROS 환경 없이 실행 | `source /opt/ros/jazzy/setup.bash` 후 다시 실행 |
| L-04 영상 동시 조합만 실패, 영상 도구 오류 | 라즈베리파이에 `x264enc` 없음 | 4.3절대로 설치 |
| `doctor.txt`에 `ros2 doctor failed` | PC에 ROS 환경이 없음 | ROS 환경을 불러온 뒤 다시 실행 |
| L-02 500 KB 조합 "발행 노드 시간 초과" | 도구 문제가 아님. 라즈베리파이가 그 크기·속도를 감당하지 못한 것 | 측정 결과로 기록 |
| 결과가 다른 날과 크게 다름 | 공유기, 장소, 라즈베리파이 기종이 바뀜 | 결과와 함께 측정 환경을 적어 두기 |

## 9. 주의 사항

- 비밀번호와 SSH 키 파일은 저장소에 넣지 않습니다.
- 라즈베리파이 IP, Wi-Fi 이름 같은 내부 정보는 공유 문서(Confluence 등)에 적지 않습니다. `evidence/`의 결과 파일에는 이런 정보가 들어 있으므로 팀 저장소 안에서만 씁니다.
- 공식 크기가 아닌 실행(`--quick`, `--trials 2` 등)이나 `PI_HOST=local` 실행은 근거로 인용하지 않습니다.
