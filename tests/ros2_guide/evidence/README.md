# ROS 2 통신 시험 공식 실행 결과 (근거 사본)

[시험 결과 보고서](../시험_결과_보고서.html)와 통신 규칙 초안이 인용하는 공식 실행 결과의 사본입니다.

- 원본은 `tests/ros2_guide/results/<실행 ID>/`에 있었고, 그 폴더는 커밋하지 않습니다.
- 근거로 인용할 공식 실행만 이 폴더에 남깁니다. 개발 실행(`--quick`, 소량 실행, `PI_HOST=local`)은 넣지 않습니다.
- 파일 형식과 필드의 뜻은 [README](../README.md)의 "결과"와 "결과 파일" 절에 있습니다.

## 인용 방법

결과를 인용할 때는 실행 ID, 항목 ID, 관측값, 파일 경로를 함께 적습니다.

> 예: 실행 `20261111-192323` L-01-A: 시작 직후 1회 발행, 50회 중 50회 수신 못 함
> ([L-01-A.json](20261111-192323/L-01-A.json))

## 함께 들어 있는 파일

- `doctor.txt`, `doctor_pi.txt`: 실행 시점의 `ros2 doctor --report` 출력.
- `preflight.json`: 2단계 사전 점검 결과.
- `parts/`: 2단계 조합(방향)별 부분 결과. 최종 JSON의 원자료입니다.

이 파일들에는 장비 이름, 내부 IP, Wi-Fi 이름 같은 내부 정보가 들어 있습니다. 팀 저장소 안에서만 쓰고, 공유 문서에는 옮기지 않습니다.
