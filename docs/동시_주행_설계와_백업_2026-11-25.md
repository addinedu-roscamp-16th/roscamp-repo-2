# JetCobot 양팔 동시 주행과 백업

2026-11-25 실물 양팔 픽앤플레이스 기준. 각 팔의 한 사이클은 **1 → 2 진입 → 3 → 2 복귀**다.

| 구간 | 정의 |
| --- | --- |
| **1 픽** | `see_center → 접근 → 미세조정 → 잡기 → 들어 올리기 → see_center` |
| **2 진입** | `see_center → pre_place` |
| **3 담기** | `pre_place → 케이스에 내려놓기 → pre_place` |
| **2 복귀** | `pre_place → see_center` |

## 목표 (사용자 결정, 2026-11-25 19:10)

- **최종 목표:** 두 팔이 각자 1 → 2 → 3 → 2를 알아서 진행한다. 제약은 **2번끼리만 겹치지 않는 것** 하나다.
- **현재 단계:** 1번과 3번은 팔별로 개별 진행한다. 2번은 아직 한 팔씩만 실행한다. 팔이 따로 움직일 때 충돌 검사는 **상대 팔의 현재→목표 경로 전체**를 포함한다(현재·목표 자세만 보는 방식은 쓰지 않음).
- **최후의 목표:** 두 팔이 서로 잘 피하면서 움직인다. 지금 2번은 다른 팔이 가만히 있고 움직이는 팔이 그 팔을 피해 간다. 나중에는 움직이는 팔이 편하도록 다른 팔이 비켜 주거나, 2번이 겹쳐도 두 팔이 서로 피해 도착하게 한다.
- 19:01 실물 결과: `pre_place` 도착 → 약 8초 정지(worker 시작 3초 + 게이트 충돌 검사 4.3초) → 왼팔 하강과 오른팔 접근 한 골 동시 출발(약 5초) → 나머지는 모두 차례대로. 게이트가 양팔 통틀어 골 하나만 실행하기 때문이다.

## 현재 구현 (2026-11-25 저녁, 팔별 실행)

**게이트** (`execution_gate.py`)

| 골 종류 | 실행 방식 |
| --- | --- |
| 한 팔 관절 골(`guarded_joint_goal`, 6관절), 그리퍼 | 그 팔의 **lane**에서 실행. 왼팔·오른팔 lane은 동시에 돈다 |
| 2번 MoveIt 궤적(`guarded_both_controller`), 12관절 골 | **단독** 실행. 두 lane이 모두 빌 때까지 기다린다. 기다리는 동안 새 lane 골도 기다린다 |

- 바쁘면 거절하지 않고 **기다린다**(취소·고장 시 이동 없이 종료).
- lane 골 충돌 검사: 내 팔 현재→목표 경로 × 상대 팔 **남은 경로(현재→목표)** 의 모든 조합(1° 간격). 상대 팔 경로와 겹치면 상대 팔이 멈출 때까지 기다렸다가 다시 검사한다. 검사와 출발은 한 번에 한 팔씩(교착 방지).
- 한 팔에서 이동 중 오류가 나면 고장 잠금이 걸리고 다른 팔도 멈춘다.

**앱** (`sam_multi_real.py`, `concurrent_pick_place:=true`)

- 담기 단계(2 진입 / 3 담기 / 2 복귀)는 **담기 칸**의 별도 worker에서 돈다. 픽 칸은 바로 다음 물체(다른 팔)의 1번을 시작한다.
- 바구니는 한 팔만 쓴다: 다음 팔의 2 진입은 먼저 담은 팔의 2 복귀가 끝난 뒤 시작한다.
- 담기 worker는 ROS 노드 이름 `dual_arm_coordinator_place`로 뜬다(같은 이름 두 노드가 응답을 잃은 11-20 문제).
- 3번 worker: `right_place_trial/stage3_place.py`(하강 IK 골 → 그리퍼 열기 → `pre_place`).

**주의**

- `fine_moveit_planning:=true`면 미세조정이 Pi로 직접 가는 SDK 동작(`sdk_slow_goal`, `sdk_linear_xy`)을 써서 **게이트를 거치지 않는다**. 그러면 상대 팔 lane의 경로 검사에 이 움직임이 안 들어간다. 동시 모드는 `fine_moveit_planning:=false`로 실행한다.
- 큰 이동 두 개를 1° 간격으로 짝지어 검사하면 검사 시간이 길어질 수 있다(19:01 양팔 골 4.3초). 실물 시간 확인 필요.
- 실물 미확인. 단위 테스트(게이트 lane 순서·경로 조합 검사, 앱 칸 넘김)만 통과.

## 실행

```bash
source /opt/ros/jazzy/setup.bash && source ~/pinky_ws/install/setup.bash &&
ROS_DOMAIN_ID=83 ros2 launch jetcobot_dual_control system.launch.py tin_case_enabled:=false
```

```bash
source /opt/ros/jazzy/setup.bash && source ~/pinky_ws/install/setup.bash &&
ROS_DOMAIN_ID=83 ros2 launch jetcobot_dual_app pick.launch.py \
  first_arm:=left concurrent_pick_place:=true fine_moveit_planning:=false
```

로그: 게이트 `left joint goal checked in …s; sending` / `… goal waiting for the running motion to finish`, 앱 `STATE STAGE2_ENTER (left): …` 다음에 바로 다른 팔 `STATE OBJECT 2/…`.
