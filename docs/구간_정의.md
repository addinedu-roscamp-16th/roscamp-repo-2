# 동작 구간 정의 (A / B / C)

2026-11-25 사용자 지정. 이후 대화와 문서는 이 이름을 쓴다.

| 구간 | 동작 | 경로 방식 |
| --- | --- | --- |
| **A** | `see_center → 픽(접근 · 미세조정 · 하강 · 잡기 · 리프트) → see_center` | 관절 골(IK) |
| **B** | `see_center → pre_place` 또는 `pre_place → see_center` | MoveIt (복귀는 진입 경로 역순 재사용) |
| **C** | `pre_place → place(하강 · 그리퍼 열기) → pre_place` | 관절 골(IK) |

- 한 팔의 한 사이클: **A → B(진입) → C → B(복귀)**.
- 예전 문서의 1 / 2 / 3번은 각각 **A / B / C**와 같다.

## 동시 진행 규칙

- 최종 목표: 두 팔이 각자 A → B → C → B를 진행하고, **B끼리만 겹치지 않는다**.
- 현재 단계: A와 C는 팔별로 동시에 진행한다. B는 한 팔씩 단독 실행한다.
- 최후의 목표: 두 팔이 서로 피하며 움직인다(다른 팔이 비켜 주거나, B가 겹쳐도 서로 피해 도착).
