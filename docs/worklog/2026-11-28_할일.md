## 할 일 2: Pi 설정 (사용자가 실행)

### 2-1. 디스커버리 설정 복사 (PC에서)
먼저 Pi에 폴더가 없는지 확인:
```bash
ssh jetcobot@192.168.0.33 'ls -la ~/iponic_net 2>/dev/null || echo 없음'
ssh jetcobot@192.168.0.22 'ls -la ~/iponic_net 2>/dev/null || echo 없음'
```
`없음`이면 복사:
```bash
scp -r ~/iponic_net jetcobot@192.168.0.33:'~/'
scp -r ~/iponic_net jetcobot@192.168.0.22:'~/'
```
- Pi는 Jazzy(확인됨)라 PC와 같은 파일을 그대로 쓴다.
- **모든 장치(PC 터미널 전부 + Pi 두 대)가 같은 모드여야 한다.** 하나라도 다르면 서로 못 찾는다. 모드를 바꾸면 그 장치의 노드를 모두 다시 띄우고 `ros2 daemon`도 다시 띄운다.
- 팀이 `net_ds.sh`(서버 주소)를 바꾸면 PC에 다시 가져와 Pi 두 대에도 똑같이 복사한다.

### 2-2. Wi-Fi 절전 영구 끄기 (각 Pi)
지금 두 Pi 모두 `Power save: on`이었다. 임시로 끄기(재부팅하면 다시 켜짐):
```bash
sudo iw dev wlan0 set power_save off && iw dev wlan0 get power_save
```
영구로 끄려면 먼저 확인:
```bash
systemctl is-active NetworkManager; nmcli -t -f NAME,DEVICE connection show --active
```
`active`면(재시작 중 Wi-Fi가 잠깐 끊김, 로봇 멈추고 브리지 끈 뒤):
```bash
printf '[connection]\nwifi.powersave = 2\n' | sudo tee /etc/NetworkManager/conf.d/wifi-powersave-off.conf && sudo systemctl restart NetworkManager
```
`inactive`면 결과를 붙여 달라고 한다(다른 방법).
