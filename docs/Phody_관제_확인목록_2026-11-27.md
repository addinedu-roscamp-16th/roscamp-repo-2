| 담기 단계에서 멈춘 뒤 이어서 하기: **B 진입** | ✅ | `fault` → `resume` → 바구니까지 가서 담고 돌아옴 |
| 담기 단계에서 멈춘 뒤 이어서 하기: **C**(바구니 위) | ✅ | `fault` → `resume` → 그리퍼 다시 열고 B 복귀 |

## 5. 오늘 실물에서 나온 문제와 처리

| 문제 | 원인 | 처리 | 상태 |
|---|---|---|---|
| 자동 실행이 `left joints are stale`(관절 상태 끊김)로 그냥 서 있음 | Pi Wi-Fi 절전 켜짐 (두 Pi 모두) | 절전 끄기 명령 안내. 코드: 끊기면 1초마다 다시 시도, 30초 넘으면 `PAUSED` | 🧪 |
| Pi가 `left_3_Joint exceeds movement limit of 180 degrees`로 거절 | 후보 고르기(TEMP B7)가 J3를 180° 넘게 돌리는 후보를 고름 | Pi와 같은 180° 검사로 그 후보를 건너뜀 | 🧪 |
| Pi 거절 뒤 U가 `physical progress unconfirmed` | Pi 거절이 "안 움직임"으로 처리되지 않음 | Pi 거절(`no motion sent`)도 "안 움직임" → U가 다시 계획 | 🧪 |
| 담기 단계에서 멈춘 뒤 U가 아무 반응 없음 | 동시 모드는 담기 단계에 복구 기록이 없었음 | 단계별로 이어서 하기 추가 | ✅ |
| 멈춘 뒤 다음 동작이 전부 거절 | 게이트 고장 잠금 (동작 중 취소하면 걸림) | `fault` = 잠금 해제, 잠금 표시 | ✅ |
| 미세조정 `TCP tilted 17.0 deg`로 시작 전 멈춤 | 계획대로 도착함. 왼팔 관절 영점 의심 | 관제 마무리 뒤 영점 확인 | ⏳ |
